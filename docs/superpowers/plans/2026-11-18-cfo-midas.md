# Midas (CFO) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Criar o agente especialista `midas` (CFO, só do Nicholson), herdando tudo da `iris`, com briefing semanal financeiro na conversa do Nicholson, e pôr a `iris` para dormir.

**Architecture:** O Midas é um especialista como a Iris: sete arquivos no gateway, escopo MCP por `alsoAllow`/`deny`, régua em skills. O código muda pouco (id `iris` fixo vira `midas`, link público sai das duas ferramentas financeiras, novo tipo `financeiro` na fila de varreduras); o resto é operação no gateway por scripts com ensaio por padrão. A régua do DRE é do DataCore e fica fora deste plano: a Tarefa 6 entrega o prompt da sessão de lá, e a skill `resultado-mensal` (etapa 2 da spec) é um plano à parte, quando o `gold.dre_mensal` estiver no ar.

**Desvio consciente da spec:** a spec pede que o servidor recuse `publicar_link` "para o Midas". O `hsos-relatorios` não sabe que agente chama (segredo compartilhado, sem identidade), e as duas ferramentas só existem para o Midas depois que a Iris dorme — então o parâmetro sai das duas para todos (Tarefa 1).

**Tech Stack:** FastAPI + asyncpg, pytest; OpenClaw gateway por `app/gateway/client.py`/`patch.py`; skills em `backend/skills/<slug>/SKILL.md` publicadas por `scripts/publicar-skills.sh --enviar`.

**Spec:** `docs/superpowers/specs/2026-11-18-cfo-midas-design.md`

## Global Constraints

- `agent_id` = `midas`; nome exibido **Midas**; workspace `/root/.openclaw/workspace-midas`; `allowed_user_ids` = os mesmos da `iris` hoje (só o Nicholson).
- Voz `pt-BR-AntonioNeural`; modelo = o mesmo que a `iris` usa hoje na config do gateway.
- **Nada escreve fora do HS.OS.** Nenhuma ferramenta nova de escrita.
- **Sem `publicar_pagina` e sem `publicar_link`** para o Midas.
- Denies obrigatórios do Midas: `sessions_send`, `sessions_spawn`, `skill_workshop`, `cron`, `gateway`, `web_fetch`, `x_search`, `web_search`, `hsos-relatorios__publicar_pagina` (deny sem prefixo `mcp__`; `alsoAllow` com `mcp__`).
- Cada um dos sete arquivos ≤ `TETO_ARQUIVO_AGENTE` (20.000) — medir com `excede_o_teto` antes de gravar. O `AGENTS.md` da Nina vive a ~500 do teto.
- Toda resposta com número diz o tipo: **medido**, **provisório** ou **incompleto**.
- Regra do gateway: **não sondar escrita sem combinar** — scripts são ensaio por padrão e só escrevem com `--aplicar`; conferência é **perguntar ao agente**.
- Iris dormir = fora do `agents.list`, JSON guardado, `agent_profiles.status='inactive'`; **nunca** apagar workspace nem linha.
- Briefing semanal: segunda (primeiro dia útil da semana), **08:00**, limite **11:00**, na conversa do Nicholson com o Midas, nunca na wiki.
- Testes do backend: `cd backend && python -m pytest tests -q` (sem banco, sem gateway). Migração aplicada por `~/projetos/bancos/.venv/bin/python ~/aplicar-hsos-040.py`, que confere o efeito.
- Changelog obrigatório em `frontend/src/data/changelog.ts` (topo do array, linguagem de quem usa).
- Fim de branch: merge local na `main` + `git push`; deploy é manual, no fim do dia.
